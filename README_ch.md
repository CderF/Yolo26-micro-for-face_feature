# YOLO26-Micro: 针对网课微表情识别的定制化轻量级架构

## 📌 项目背景与痛点 (Motivation)
本项目基于 Ultralytics 的 YOLO26 实验性分支进行深度二次开发。
原始 YOLO 架构（以 P3-P4-P5 为基准）在面对“线上网课环境下面部微表情识别”这一特定任务时存在致命缺陷：
1. **分辨率坍塌**：微表情动作幅度极小（常不足 10 像素），在深层 P5 网络（下采样 32 倍）中会因特征尺寸过小而被物理抹除。
2. **高频噪声干扰**：网课背景复杂（衣柜、屏幕反光），易将微弱的面部肌肉抽动信号淹没。

为此，我们设计了 **YOLO26-Micro** 架构，核心理念为：**“砍掉P5，引入P2，最后加以重兵把守（注意力）”**。

---

## 🛠️ 核心架构魔改亮点 (Architecture Highlights)

### 1. 废弃 P5 瞎子层，重仓 P2 超清层
* 斩断了 Backbone 中通往 P5 (20x20) 的路径，将最高层限制在 P4 (40x40)。
* 从 Backbone 极浅层引出了 **P2 特征层（160x160，仅下采样 4 倍）**，这使得即使是 4 个像素的眼角抽动，也能占据完整的特征网格。

### 2. C2PSA 充当 P2 层防波堤
* 在 P2 层（包含海量背景高频噪声）进入 Neck 融合前，强行绑定了 `C2PSA`（位置空间注意力机制）。
* 利用注意力机制压制背景网格激活值，点亮五官轮廓，防止后续特征融合时微弱的微表情信号被噪声冲刷。

### 3. 多尺度立交桥重构 (Neck Reconstruction)
* 将原本的 `P5-P4-P3` 的 FPN+PANet 特征融合网络，重构为 **`P4-P3-P2`** 的级联融合。
* 检测头（Detect Head）的三个输出端分别转变为监控：**[极大分辨率(P2), 高分辨率(P3), 中等分辨率(P4)]**。

### 4. 突破物理极限的 Scale 缩放
* 为满足 `C2PSA` 内部隐藏 `0.5` 压缩率后依然能分配至少 1 个多头注意力的底层数学要求（避免 `ZeroDivisionError`）。
* 将模型规模从 Nano 提升至 Small：`scales: s: [0.33, 0.50, 1024]`。在保证 1 个注意力头精准运作的同时，将整体参数量死死压制在端侧实时推理的阈值内。
